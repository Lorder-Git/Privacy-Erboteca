Politique de confidentialité d'Erboteca

Dernière mise à jour : 26/11/2026  ·  Version : 2.1

Ceci est une traduction. Le texte de référence est la version italienne : en cas de différence entre les versions, la version italienne prévaut.

En bref. Erboteca fonctionne sur votre téléphone. Les données que vous saisissez y restent, sauf lorsque vous choisissez vous-même une fonction qui les envoie (vous les trouverez au point 3) : nous ne les vendons pas et nous ne les utilisons pas à des fins publicitaires. Aucun compte n'est nécessaire et le service est protégé : connexions chiffrées, aucune publicité, aucun suivi. Nous protégeons vos droits conformément au règlement européen sur la protection des données (RGPD) et nous sommes heureux de vous aider : écrivez-nous quand vous le souhaitez.

1. Qui est le responsable du traitement

Hubert Montero, développeur indépendant — marketplace-apps.com
E-mail : premium@marketplace-apps.com

2. Où restent vos données

Les données que vous saisissez dans Erboteca (favoris, notes personnelles, garde-manger et paramètres) sont enregistrées uniquement sur votre téléphone, dans la mémoire réservée à l'application.

3. Quand l'application utilise internet

L'application se connecte à internet uniquement pour ces fonctions :

  • Mises à jour : l'application vérifie s'il existe une nouvelle version et, si c'est le cas, la télécharge depuis le site ; elle n'envoie ni les données que vous avez saisies ni votre adresse e-mail. Comme pour toute connexion à internet, les prestataires voient l'adresse IP du téléphone ; nous ne l'enregistrons pas.
  • Achat de Premium : le paiement s'effectue sur PayPal. Nous recevons votre adresse e-mail et les données de la commande pour vous envoyer la clé et pour les obligations fiscales.
  • Activation de Premium : l'application envoie la clé (qui contient l'adresse e-mail utilisée pour l'achat) et un code du téléphone créé par l'application (il ne contient ni votre nom ni votre numéro), pour vérifier que la clé est valide et utilisée sur les appareils autorisés. Jamais les données que vous avez saisies dans l'application.
  • Contenus : l'application télécharge les fiches et les formules avec les prix qu'elle affiche, y compris dans la version gratuite ; les contenus de Premium uniquement après l'activation. Elle n'envoie pas les données que vous avez saisies. Les photos de Premium sont téléchargées lorsque vous ouvrez la fiche : la requête ne contient ni la clé ni aucune autre donnée vous concernant. Comme pour toute connexion à internet, les prestataires voient l'adresse IP du téléphone ; nous ne l'enregistrons pas.
  • Liens externes : si vous ouvrez une autre application ou un site externe, la politique de confidentialité de ce service s'applique.

4. Ce qu'Erboteca ne fait pas

  • Elle n'a ni compte ni inscription.
  • Elle n'affiche pas de publicité et ne fait pas de profilage.
  • Elle n'utilise pas d'outils de suivi ou de statistiques de tiers.
  • Elle ne vend ni ne cède vos données à personne.
  • Elle ne lit pas les contacts, les messages, la position ni les autres applications.
  • Elle ne prend pas de décisions fondées uniquement sur un traitement automatisé qui produisent des effets juridiques vous concernant ou qui vous affectent de manière similaire (art. 22 RGPD).

6. Pendant combien de temps

  • Données sur le téléphone : jusqu'à ce que vous les supprimiez ou désinstalliez l'application.
  • Enregistrement de la commande pour vous envoyer la clé : 90 jours.
  • Données de la vente : elles restent sur le compte PayPal du vendeur pendant 10 ans, comme l'exigent les règles sur la conservation des documents fiscaux (art. 2220 du Code civil italien).
  • Activations : tant que la licence est utilisée ; supprimées dans un délai de 90 jours après la dernière utilisation.
  • Adresse IP : nous ne l'enregistrons pas ; les prestataires la conservent pendant la courte durée prévue par leurs services.
  • Messages et demandes : si vous avez effectué un achat, nous les conservons pendant 1 an (licence mensuelle), 3 ans (annuelle) ou 5 ans (triennale) à compter du dernier message, et en tout cas pas plus de 26 mois après l'expiration de la licence si cette date arrive en premier : c'est la période pendant laquelle un litige sur la licence pourrait survenir. Si vous n'avez pas effectué d'achat, 12 mois à compter du dernier message, pour donner suite à d'éventuelles demandes ultérieures. Si un litige est en cours, nous les conservons jusqu'à sa conclusion. Les demandes relatives à vos droits et nos réponses suivent les mêmes durées.

7. À qui parviennent les données

Nous ne transmettons vos données à personne pour ses propres fins.

  • Prestataires de services informatiques qui traitent les données pour notre compte (art. 28 RGPD) : Cloudflare (États-Unis), Vercel (États-Unis), Supabase (société dont le siège est à Singapour ; données conservées dans l'Union européenne), Resend (États-Unis).
  • Responsables du traitement indépendants, chacun avec sa propre politique de confidentialité : PayPal.

Transferts hors de l'Union européenne : Cloudflare, Vercel et Resend adhèrent au cadre de protection des données UE-États-Unis (Data Privacy Framework), reconnu adéquat par la Commission européenne ; pour Supabase, les clauses contractuelles types approuvées par la Commission européenne s'appliquent. Vous pouvez nous demander une copie des garanties à l'adresse premium@marketplace-apps.com.

8. Vos droits

Le RGPD vous garantit le droit d'accéder à vos données, de les rectifier, de les effacer, d'en limiter l'utilisation, de vous y opposer et de les recevoir dans un format lisible.

  • Pour les données sur le téléphone, vous le faites directement depuis l'application : en supprimant les notes et le garde-manger dans Altro › Note personali (Plus › Notes personnelles) et Altro › Dispensa (Plus › Garde-manger), et les favoris avec « Togli dai preferiti » (Retirer des favoris) dans la fiche, ou en désinstallant l'application.
  • Pour le peu de données que nous recevons, écrivez-nous à premium@marketplace-apps.com : nous vous répondons dans un délai d'un mois. Pour les retrouver plus rapidement, vous pouvez nous indiquer la clé de licence ou nous écrire depuis l'adresse e-mail de l'achat.
  • Vous pouvez retirer à tout moment un consentement donné, sans conséquence sur ce qui a été fait auparavant.
  • Si vous estimez que vos droits ne sont pas respectés, vous pouvez introduire une réclamation auprès du Garante per la protezione dei dati personali, l'autorité italienne de protection des données (garanteprivacy.it).

Droit d'opposition. Lorsque nous traitons des données pour notre intérêt légitime (protéger les licences, assurer la sécurité du service), vous pouvez vous y opposer quand vous le souhaitez en écrivant à premium@marketplace-apps.com. Nous arrêtons, sauf motifs légitimes prépondérants, que nous vous expliquerons.

9. Sécurité

Les données sur le téléphone se trouvent dans la mémoire réservée à l'application, protégée par le système d'exploitation. Les communications avec nos services sont chiffrées. Nous vous conseillons de garder le verrouillage de l'écran activé et votre téléphone à jour.

10. Mineurs

Erboteca est destinée aux personnes majeures (18 ans) et ne collecte pas sciemment de données de mineurs.

11. Avertissement

Erboteca est un outil de consultation et ne constitue pas un avis médical. Avant d'utiliser une plante ou une recette, demandez conseil au médecin ou au pharmacien.

12. Modifications

Si cette politique change, la nouvelle version est publiée ici avec sa date.
